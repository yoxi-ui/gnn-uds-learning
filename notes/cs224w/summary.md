# CS224W 学习总结

## 1. 图表示

图由节点、边、节点特征和边特征组成。任务可以是节点级、边级或图级。排水管网中，节点对应 manhole/outfall，边对应 conduit，动态水力量是时序节点/边特征。

## 2. 传统方法

节点度、中心性、共同邻居和图统计量能够提供结构特征，但依赖人工设计，难以完整表达复杂的局部结构、边特征和时间关系。

## 3. 节点嵌入

DeepWalk 通过随机游走产生节点序列，再用 Skip-gram 学习共现表示。它强调结构共现，通常先学习表示再做下游任务；GNN 则根据具体任务损失进行端到端消息传递和参数学习。

## 4. 消息传递

```text
Message → Aggregate → Update
```

邻居聚合必须对节点排列不敏感。求和、平均、最大值和注意力加权都是常见聚合方法。参数共享让所有节点使用同一套局部规律，并提高泛化能力。

## 5. GNN 堆叠

一层通常接收 1-hop 信息，两层接收 2-hop 信息，三层接收 3-hop 信息。层数太深可能出现过平滑和过压缩，因此模型深度必须和任务所需的空间范围匹配。

## 6. 与排水管网的联系

排水网络不是静态无向图：水流具有方向，管道有边属性，状态随时间变化。因此实际模型要考虑有向/无向建图、边特征、时间窗口、边界 runoff 和多步预测误差。
