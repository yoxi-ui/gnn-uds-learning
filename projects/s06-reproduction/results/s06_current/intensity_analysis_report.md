# S06 降雨工况稳健性分析：总雨量与最大逐步雨强

本报告是冻结 `GATConv + Conv1D` 基线的只读后处理，不重新训练、不重新推理。事件级误差来自冻结基线的 teacher-forced 60→60 评估；bootstrap 以事件为重采样单位。

## 数据与阈值

- 输入目录：`D:\论文\GNN-UDS\surrogate\model\shunqing\s06_baseline_analysis_10000_best`
- 可用事件级误差：30 个（validation=27，heldout_test=3）；训练事件仅用于拟合分组阈值。
- 训练事件数：118；阈值方法：training-only tertiles。
- 总雨量 q1/q2：26.6000 / 42.2000 mm。
- 最大逐步雨强 q1/q2：7.3000 / 13.6000 mm/h。
- bootstrap：10,000 次、事件内重采样、seed=20260928、百分位 95% CI。

验证集连续相关性表明，最大逐步雨强与误差的线性关联强于总雨量；这支持将峰值强度作为补充工况描述变量，但不单凭分组差异作绝对结论。

## 解释边界

- 验证集总雨量小雨组只有 3 个事件；最大逐步雨强低峰组为 5 个事件。小样本组的 bootstrap 区间和标准差应作为不确定性提示，而不是稳定总体参数。
- 三个 held-out 测试事件不覆盖三档强度（按最大逐步雨强为 1 个 high_peak、2 个 medium_peak），因此测试事件只能作为补充核查，不能独立证明三组趋势。
- 三场测试事件的峰值雨强均未超出训练事件最大峰值（当前测试最大 24.0 mm/h；训练最大 36.6 mm/h），所以现有结果不能表述为“未见强降雨泛化失败”。
- 当前评估是 teacher-forced，尚未代表长期自回归闭环误差；峰值强度与误差的关系是事件级关联，不是因果证明。
